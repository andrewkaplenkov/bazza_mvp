## Быстрый старт

### 1. Настройка `.env`

Скопируй `.env.example` в `.env` и заполни два токена: BOT_TOKEN & GROQ_API_KEY

### 2. Запуск

```commandline
docker compose up --build
```

### 3. Что посмотреть

Swagger API: 
http://localhost:8000/docs  
Админка:
http://localhost:3001  
Mini App:
http://localhost:3000
